# 另一种人生 · Parallel You

Public, static cinematic narrative preview of the Counterfactual Life Simulator. Open the GitHub Pages URL to try three authored synthetic stories or enter your own scenario. The changed choice opens WORLD A; the first divergence is Chapter 01, followed by five full-screen chapters, present day, an animated meeting, a fictional conversation, a three-line interactive SVG epilogue, and a visual share card. WORLD B unlocks at the epilogue. JSON-driven CSS environments, a growing SVG timeline, and immersive, quick, and reduced-motion pacing use the same story data. Inputs stay in the current browser page and are not sent to a model.

Before the decision fork, a three-mirror Self Model offers independent Reality, Big Five, MBTI narrative-label, and traditional Ba Zi / Zi Wei symbolic lenses. Reality, psychology, symbolic, and fusion modes use the same story UI and worldlines; changing modes only changes presentation and explicitly bounded interpretation. The 20 public-domain Mini-IPIP items use standard reverse-key raw scoring with unvalidated Chinese helper wording; scores are not percentiles or diagnoses. Charts are computed locally by the pinned, MIT-licensed `lunar-javascript` and `iztro` libraries, with [bundled notices](THIRD_PARTY_NOTICES.txt). Birth date, time and city are optional, are not sent to a server, and unknown birth time does not produce a precise chart. Symbolic charts are not reality facts or predictions.

The preview is a hypothetical storytelling tool, not a record of history or a prediction of the future. The `baseline` and `iu-enhanced` switches at `?dev=1` currently use the same local deterministic demo adapter as `mock`; real model transports are not implemented and require a separate authorized CONFIG_LOCK. The default share card and PNG exclude private inputs and conversation. A full-story replay link requires explicit opt-in and contains the user's original life-story inputs in its URL fragment; birth details, personality answers, MBTI label and chat are not included.

This public repository contains only static site assets and synthetic demo data. It does not contain the experimental implementation or internal evidence.
