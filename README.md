# 另一种人生 · Parallel You

Public, static cinematic narrative preview of the Counterfactual Life Simulator. Open the GitHub Pages URL to try three authored synthetic stories or enter your own scenario. Each path unfolds through six scenes, a meeting with an alternate self, and a fictional conversation. Inputs stay in the current browser page and are not stored or sent to a model.

The preview is a hypothetical storytelling tool, not a record of history or a prediction of the future. The `baseline` and `iu-enhanced` switches at `?dev=1` currently use the same local deterministic demo adapter as `mock`; real model transports are not implemented and require a separate authorized CONFIG_LOCK. Sharing sends only a fictional quote and the public entry URL, never your input or conversation.

This public repository contains only static site assets and synthetic demo data. It does not contain the experimental implementation or internal evidence.
