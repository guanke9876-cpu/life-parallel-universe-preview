# 另一种人生 · Parallel You

Public, static cinematic narrative preview of the Counterfactual Life Simulator. Open the GitHub Pages URL to try three authored synthetic stories or enter your own scenario. Choose one worldline, experience six full-screen chapters, reach the present day, meet an alternate self, have a fictional conversation, then share a card. The other worldline unlocks at the epilogue. Immersive and quick reading modes use the same story data. Inputs stay in the current browser page and are not stored or sent to a model.

The preview is a hypothetical storytelling tool, not a record of history or a prediction of the future. The `baseline` and `iu-enhanced` switches at `?dev=1` currently use the same local deterministic demo adapter as `mock`; real model transports are not implemented and require a separate authorized CONFIG_LOCK. The default share card and PNG exclude private inputs and conversation. Including the complete story and chat in shared text requires explicit opt-in.

This public repository contains only static site assets and synthetic demo data. It does not contain the experimental implementation or internal evidence.
