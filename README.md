# 另一种人生 · Parallel You

Public, static cinematic narrative preview of the Counterfactual Life Simulator. Open the GitHub Pages URL to try three authored synthetic stories or enter your own scenario. The changed choice opens WORLD A; the first divergence is Chapter 01, followed by five full-screen chapters, present day, an animated meeting, a fictional conversation, a three-line interactive SVG epilogue, and a visual share card. WORLD B unlocks at the epilogue. JSON-driven CSS environments, a growing SVG timeline, and immersive, quick, and reduced-motion pacing use the same story data. Inputs stay in the current browser page and are not sent to a model.

The preview is a hypothetical storytelling tool, not a record of history or a prediction of the future. The `baseline` and `iu-enhanced` switches at `?dev=1` currently use the same local deterministic demo adapter as `mock`; real model transports are not implemented and require a separate authorized CONFIG_LOCK. The default share card and PNG exclude private inputs and conversation. A full-story replay link requires explicit opt-in and contains the user's original inputs in its URL fragment; chat is not included.

This public repository contains only static site assets and synthetic demo data. It does not contain the experimental implementation or internal evidence.
